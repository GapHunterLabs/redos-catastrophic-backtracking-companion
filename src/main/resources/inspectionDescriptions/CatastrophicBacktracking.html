Reports a Java regex literal in Pattern.compile("...") or "...".matches("...") with a catastrophic-backtracking structure: a nested unbounded quantifier such as (a+)+, or an unbounded quantified alternation with overlapping branches such as (a|a)*.

One crafted input can keep the matcher busy for an extremely long time and tie up a server thread (CWE-400, regular expression denial of service). Rewrite the pattern so that each part of the input can be matched in only one way.
